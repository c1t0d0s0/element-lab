## 🌟 概要

**元素ラボ (Element Lab)** は、TypeScript と HTML5 Canvas で構築されたインタラクティブな化学学習シミュレーションです。
画面上に元素（原子）や化合物を配置し、バーナーで加熱したり冷却スプレーで冷やしたり、点火スパークを散らしたりしながら、リアルな化学反応（水の合成、鉄のサビ、燃焼、酸化還元、中和など）や物理現象（浮力、状態変化、熱伝導）を体験できます。

文部科学省の学習指導要領（中学校理科第2分野・高等学校化学基礎/化学）の学習内容を参考にしており、遊びながら確かな化学の基礎知識を身につけることができます。

## ✨ 主な特徴

- **⚛️ 全118元素完全収録の周期表**
  - 水素（H：原子番号1）からオガネソン（Og：原子番号118）まで全元素データを網羅。
  - 各元素の原子番号・族・周期・分類・原子半径・融点/沸点・原子量・モル質量・学習ポイントを収録。
  - **原子半径の視覚的スケーリング**: 周期表の傾向に合わせて、ヘリウム（He）は小さく、フランシウム（Fr）は大きく直感的に描画。

- **💨 リアルな物理演算・熱力学シミュレーション**
  - **浮力と空気抵抗**: 空気の平均分子量（約 $28.8\text{ g/mol}$）との比較により、軽い気体（$\text{He}$ や $\text{H}_2$）は上空へとふわふわ浮かび、重い気体（$\text{CO}_2$ など）は下方へ沈降。
  - **温度と相変化（状態変化）**: 粒子の温度と融点・沸点に応じて、リアルタイムに「固体 🧊」「液体 💧」「気体 ♨」へと変化。
  - **📈 温度グラフ（中1「状態変化と温度」）**: 観察カードの「📈 温度グラフ」を押すと、その粒の温度の変わり方を時間とともにグラフにします。融けている間や沸騰している間は、加えた熱が状態を変えるのに使われる（潜熱）ので、温度は融点・沸点のまま平らになります（黄色の線。融点・沸点は点線で表示）。ミッション24で、氷を加熱して0℃と100℃の平らな部分を確かめます。
  - **熱伝導と対流**: 粒子同士の衝突による熱の移動、加熱された気体の上昇気流（熱気球効果）やブラウン運動をシミュレート。
  - **高温発光・危険性表示**: 鉄（$\text{Fe}$）は500℃以上で赤熱（オレンジ・白熱発光）。有毒気体（$\text{CO}$ や $\text{HCl}$）には警告オーラを表示。

- **🔥 充実した化学反応エンジン**
  - **水の合成**: $2\text{H} + \text{O} \to \text{H}_2\text{O}$、または水素ガスと酸素ガスの燃焼爆発 $2\text{H}_2 + \text{O}_2 \to 2\text{H}_2\text{O}$。
  - **鉄のサビ（常温 vs 高温）**:
    - *赤サビ（酸化鉄(III)）*: 常温で水と酸素の両方に触れることで徐々に赤サビ（$\text{Fe}_2\text{O}_3\cdot n\text{H}_2\text{O}$）が進行。
    - *黒サビ（四酸化三鉄）*: 赤熱した鉄（>500℃）に高温の水蒸気（>100℃）を通すと、良質な保護被膜である黒サビ（$\text{Fe}_3\text{O}_4$）と水素ガス（$\text{H}_2$）が発生。
  - **燃焼と有毒気体**:
    - マグネシウムの燃焼: $2\text{Mg} + \text{O}_2 \to 2\text{MgO}$（まばゆい白色の閃光と発熱を伴い、白色粉末の酸化マグネシウムを生成する中学2年最重要実験）。
    - 二酸化炭素中でのマグネシウム燃焼: $2\text{Mg} + \text{CO}_2 \to 2\text{MgO} + \text{C}$（CO₂中でも燃焼が持続し、黒い炭素が析出）。
    - 完全燃焼: $\text{C} + \text{O}_2 \to \text{CO}_2$（二酸化炭素）。
    - 不完全燃焼: $2\text{C} + \text{O}_2 \to 2\text{CO}$（酸素が足りないときに起こる。無色・無臭で人体に猛毒な一酸化炭素）。
    - メタン燃焼: $\text{CH}_4 + 2\text{O}_2 \to \text{CO}_2 + 2\text{H}_2\text{O}$。
  - **中学の必修実験**:
    - 酸化銀の熱分解（中2）: $2\text{Ag}_2\text{O} \to 4\text{Ag} + \text{O}_2$。
    - アンモニアの発生（中1・中2）: $2\text{NH}_4\text{Cl} + \text{Ca(OH)}_2 \to \text{CaCl}_2 + 2\text{NH}_3 + 2\text{H}_2\text{O}$（加熱）。
    - マグネシウムと塩酸: $\text{Mg} + 2\text{HCl} \to \text{MgCl}_2 + \text{H}_2$。
    - 白い沈殿ができる中和（中3）: $\text{H}_2\text{SO}_4 + \text{Ba(OH)}_2 \to \text{BaSO}_4\downarrow + 2\text{H}_2\text{O}$。
    - 銅と硫黄の化合（中2）: $\text{Cu} + \text{S} \to \text{CuS}$（教科書の化学式。実際には $\text{Cu}_2\text{S}$ も多くできる）。
  - **身近な有機物**:
    - エタノールの燃焼（アルコールランプ）: $\text{C}_2\text{H}_5\text{OH} + 3\text{O}_2 \to 2\text{CO}_2 + 3\text{H}_2\text{O}$。
    - ぬるま湯（30〜40℃）でのアルコール発酵（酵母は省略）: $\text{C}_6\text{H}_{12}\text{O}_6 \to 2\text{C}_2\text{H}_5\text{OH} + 2\text{CO}_2$。
    - アルコールが酢になる（酢酸菌は省略）: $\text{C}_2\text{H}_5\text{OH} + \text{O}_2 \to \text{CH}_3\text{COOH} + \text{H}_2\text{O}$。
    - 酢と重曹: $\text{CH}_3\text{COOH} + \text{NaHCO}_3 \to \text{CH}_3\text{COONa} + \text{H}_2\text{O} + \text{CO}_2$。
    - エタノールからエチレン（濃硫酸・160℃以上）、アセチレンからエチレン（$\text{H}_2$・Ni触媒）、水蒸気でエタノールにもどす（$\text{H}_3\text{PO}_4$ 触媒・250〜350℃）。
    - エチレンとブドウ糖の燃焼（ブドウ糖は呼吸と同じ式）。
  - **酸化還元実験**:
    - 酸化銅の炭素還元: $2\text{CuO} + \text{C} \to 2\text{Cu} + \text{CO}_2$（中学理科の最重要実験）。
  - **酸・アルカリ・中和**:
    - 中和反応: $\text{HCl} + \text{NaOH} \to \text{NaCl} + \text{H}_2\text{O}$（食塩水と中和熱の生成）。
    - 気体の中和（白煙反応）: $\text{NH}_3 + \text{HCl} \to \text{NH}_4\text{Cl}$（塩化アンモニウム白煙）。
    - 金属と酸の反応: $\text{Zn} + 2\text{HCl} \to \text{ZnCl}_2 + \text{H}_2$（亜鉛が溶けて水素が発生）。
  - **🧪 自由実験（サンドボックス） & 工業的製法**:
    - **過酸化水素水（$\text{H}_2\text{O}_2$）の合成と触媒分解**:
      - 合成: $\text{H}_2\text{O} + \text{O} \to \text{H}_2\text{O}_2$（元素ラボだけのゲーム上の近道。実際にはこの反応では作られない）
      - $\text{MnO}_2$ 触媒分解: $2\text{H}_2\text{O}_2 + \text{MnO}_2 \to 2\text{H}_2\text{O} + \text{O}_2 + \text{MnO}_2$（激しい酸素ガス発生・触媒は不変）
    - **硫酸（$\text{H}_2\text{SO}_4$）の接触法プロセス**:
      - $\text{S} + \text{O}_2 \to \text{SO}_2 \to 2\text{SO}_3 \to \text{H}_2\text{SO}_4$（硫黄の燃焼・酸化・水和による強酸生成）
    - **鉄と硫黄の化合（中学2年最重要）**:
      - $\text{Fe} + \text{S} \to \text{FeS}$（硫化鉄の生成・赤熱反応） & $\text{FeS} + 2\text{HCl} \to \text{H}_2\text{S} + \dots$（腐卵臭気体発生）
    - **ハーバー・ボッシュ法（アンモニア合成）**:
      - $\text{N}_2 + 3\text{H}_2 \to 2\text{NH}_3$
    - **石灰石・石灰水サイクル**:
      - 熱分解: $\text{CaCO}_3 \to \text{CaO} + \text{CO}_2$（生石灰の生成）
      - 水和発熱: $\text{CaO} + \text{H}_2\text{O} \to \text{Ca(OH)}_2$（激しい発熱湯）
      - 二酸化炭素検出: $\text{Ca(OH)}_2 + \text{CO}_2 \to \text{CaCO}_3 + \text{H}_2\text{O}$（石灰水の白濁）
      - 気体発生: $\text{CaCO}_3 + 2\text{HCl} \to \text{CaCl}_2 + \text{H}_2\text{O} + \text{CO}_2$（激しい発泡）

- **🔥 炎色反応シミュレーション（花火の着色原理・リアカー無きK村…）**
  - 金属元素やその化合物をバーナーで加熱したり点火すると、特有の美しい炎（炎色反応）が立ち上ります。
  - **Li（リチウム）**: 深赤色（深紅）
  - **Na（ナトリウム・食塩 NaCl）**: 鮮やかな黄色（D線スペクトル）
  - **K（カリウム）**: 淡赤紫色（赤紫）
  - **Cu（銅・CuO）**: 鮮やかな青緑色
  - **Ca（カルシウム・CaCl₂）**: 橙赤色（橙）
  - **Sr（ストロンチウム）**: 深赤色（紅）
  - **Ba（バリウム）**: 黄緑色
  - **Cs（セシウム）**: 青紫色
  - **Rb（ルビジウム）**: 深赤色（赤紫がかる）
  - インスペクターや周期表、図鑑に炎色反応の名称および語呂合わせ（*リアカー無きK村動力借りるとするもくれない*）を完全掲載。

- **💧 もののとけ方・溶解度（小5「もののとけ方」／中1「溶解度」）**
  - 食塩（$\text{NaCl}$）・硝酸カリウム（$\text{KNO}_3$）・ミョウバン・砂糖（スクロース）は液体の水にふれると溶けて見えにくくなりますが、水溶液の中に残っていて、質量も変わりません。
  - 溶ける量は本当の溶解度の表（水100 gあたりの g、温度で補間）に従い、水の量に比例します。溶けきれない分は溶け残ります（飽和水溶液）。
  - 冷やしたり水を蒸発させたりすると、溶けきれなくなった分が結晶として出てきます（再結晶）。$\text{KNO}_3$ とミョウバンは温度による変化が大きく、食塩はほとんど変わらないので蒸発で取り出します。
  - 電解質の水溶液は電気を通し、砂糖水は通しません。インスペクターでは溶けている量と飽和かどうか、図鑑では溶解度の表を見られます。

- **⚡ 電気・電気分解・導電性シミュレーション（中学・高校化学最重要）**
  - **⚡ 電気ツール**: 画面をタップ・なぞることで、青白く走る放電アークとともに通電・電気分解を行います。
  - **水の電気分解**: $2\text{H}_2\text{O} \xrightarrow{\text{電気}} 2\text{H}_2 \uparrow + \text{O}_2 \uparrow$（陰極に水素、陽極に酸素が体積比 $2:1$ でブクブク発生！）。純水は電気をほとんど通さないため、水酸化ナトリウムを溶かして通電します。
  - **塩化銅の電気分解**: $\text{CuCl}_2 \xrightarrow{\text{電気}} \text{Cu} \downarrow + \text{Cl}_2 \uparrow$（赤褐色の銅が析出し、黄緑色で有毒・刺激臭の塩素ガスが発生）。
  - **食塩水の電気分解**: $2\text{NaCl} + \dots \xrightarrow{\text{電気}} \text{Cl}_2 \uparrow + \dots$（塩素ガスの工業的発生）。
  - **金属の導電性とジュール熱**: 金属粒子（$\text{Fe}, \text{Cu}, \text{Al}$ 等）や炭素（$\text{C}$）に電気が触れると、粒子間を稲妻アークが連鎖伝導し、ジュール熱で温度が上昇！
  - **インスペクターの導電性表示**: 粒子が「良導体」「電解質」「絶縁体」のどれに該当するかをリアルタイムに診断。

- **⚖️ 質量保存の法則（中2「化学変化と質量」）**
  - 天秤にのせた容器の中で、$\text{CaCO}_3 + 2\text{HCl} \rightarrow \text{CaCl}_2 + \text{H}_2\text{O} + \text{CO}_2$ のような気体が出る反応を起こします。蓋をしていれば天秤の値は変わらず、蓋がない（または外した）容器では、泡になって出た $\text{CO}_2$ が外へ出ていき、ちょうどその分だけ軽くなります。
  - 化合物の粒の質量は原子量の合計なので、どの反応でも前後の質量がぴったり同じです。
  - ミッション21で両方の結果を確かめます。

- **🔋 イオンの見える化（中3「イオン」）**
  - 水に溶けた（または融けた）電解質は、分かれたイオンとして描かれます（例: $\text{NaCl} \rightarrow \text{Na}^+ + \text{Cl}^-$、$\text{CuCl}_2 \rightarrow \text{Cu}^{2+} + 2\text{Cl}^-$）。陽イオンは赤いふち、陰イオンは青いふちです。塩化水素のような分子の酸は水に溶けたときだけ分かれ、弱い酸（酢酸・リン酸）は一部だけ分かれます。砂糖は分かれません。
  - ⚡ ツールの **🔋 電極** モードでは、ビーカーに炭素棒の電極と電源をつなぎます。電流を流すと陽イオンは陰極（−）へ、陰イオンは陽極（＋）へ動き、電気分解でできた物質がそれぞれの電極に出てきます（陰極に銅・陽極に塩素、陰極に水素・陽極に酸素が 2 : 1）。
  - ミッション20で、イオンの動きを見ながら塩化銅水溶液を電気分解します。

- **⚙️ 金属のイオンへのなりやすさと電池（中3「化学変化と電池」）**
  - 金属を、それよりイオンになりにくい金属のイオンの水溶液に入れると、その金属が出てきます: $\text{Zn} + \text{CuSO}_4 \rightarrow \text{ZnSO}_4 + \text{Cu}$、$\text{Mg} + \text{ZnSO}_4 \rightarrow \text{MgSO}_4 + \text{Zn}$、硫酸銅水溶液と鉄、銀樹 $\text{Cu} + 2\text{AgNO}_3 \rightarrow \text{Cu(NO}_3)_2 + 2\text{Ag}$。どれも水に溶かしたときだけ起こり、逆向き（銅を硫酸亜鉛水溶液に入れるなど）では変化しないので、Mg ＞ Zn ＞ Cu ＞ Ag の順がわかります。
  - ⚡ ツールの **⚙️ 電池** モードでは、ビーカーをダニエル電池にします。亜鉛板（−極）と銅板（＋極）をセロハンでへだて、導線でモーターにつなぎます。亜鉛板の側に電解質の水溶液、銅板の側に硫酸銅水溶液を入れるとモーターが回り、電子が亜鉛板から導線を通って銅板へ動きます。亜鉛は $\text{Zn}^{2+}$ になってとけ出し（亜鉛板がうすくなる）、銅板には銅が出てきます。硫酸銅を亜鉛板の側に入れると、亜鉛板に直接銅が出て電流は流れません。
  - ミッション22で3つの金属をくらべ、ミッション23でダニエル電池でモーターを回します。

- **🎓 初心者向けインタラクティブ・チュートリアル**
  - 初めての方でも迷わず遊べる6ステップの実践型チュートリアル（元素配置、水の合成、バーナー加熱・沸騰、耐熱フラスコの設置、インスペクター観察）。
  - 各ステップで次に触るべきツールやボタンが光って誘導（ハイライト機能）。いつでも再開可能。

- **🎯 学習クエスト & 化合物図鑑**
  - 「水を作ろう」「軽い気体を浮かべよう」「赤サビと黒サビを作ろう」「炎色反応を観察しよう」など、理科の単元に沿ったミッション形式で学べるクエスト機能。
  - 新たに合成した化合物を記録し、日常生活での用途や学習ポイントを学べる化学図鑑。
  - 粒子にカーソルを合わせるかタップするだけで温度・状態・分子量・炎色反応・解説が確認できるインスペクター。

- **🔊 Web Audio API による効果音**
  - 外部音声ファイル不要のプロシージャル（動的合成）サウンドエンジン（火花音、水滴音、爆発音、サビ進行音、クエスト達成ファンファーレなど）。

- **📱 PC・スマホ両対応（マルチプラットフォーム）**
  - マウス操作はもちろん、スマートフォンのタッチ操作にも最適化。

## 🎮 操作方法・ツール一覧

| ツール | アイコン | 説明 |
| :--- | :---: | :--- |
| **配置 (Spawn)** | 🧪 | 下部パレットまたは周期表から選択した元素・化合物をキャンバスに配置します。 |
| **フラスコ (Flask)** | 🏺 | 実験用耐熱ガラス器具（三角フラスコ・ビーカー・丸底試験管）をワンタップで設置し、液体を注いだり加熱できます。 |
| **加熱 (Heat)** | 🔥 | バーナーで周囲を加熱（最高1800℃）。状態変化や熱化学反応を起こします。 |
| **冷却 (Cool)** | ❄️ | 冷却スプレーで周囲を急速冷却（氷点下へ）。気体を凝縮・液体を凍結させます。 |
| **電気 (Electricity)** | ⚡ | **放電**: なぞったところに電気を流します（導電性・電気分解）。**電極**: ビーカーに電極をつなぎ、イオンの動きを見ながら電気分解します。**電池**: ビーカーをダニエル電池にして電気をつくります。 |
| **点火 (Spark)** | ⚡ | 電気火花を散らし、水素爆発などの可燃性混合気に引火させます。 |
| **耐熱壁 (Wall)** | 🧱 | 粒子や熱を遮断する固定壁を配置し、実験室内に密閉容器を作れます。 |
| **消去 (Erase)** | 🧹 | ブラシが触れた粒子を個別に消去します。 |
| **観察 (Inspect)** | 🔍 | 粒子を選択し、現在の温度・状態・質量・学習ポイントを確認します。**📈 温度グラフ**で、その粒の温度の変わり方を記録できます。 |

## 🚀 セットアップと実行方法

### 必要要件

- Node.js（v18.0.0 以上を推奨）
- npm（v9.0.0 以上）

### インストール

1. リポジトリをクローンまたはディレクトリに移動します:
   ```bash
   cd element-lab
   ```

2. 依存パッケージをインストールします:
   ```bash
   npm install
   ```

### 開発サーバーの起動

```bash
npm run dev
```
ターミナルに表示されたURL（通常は `http://localhost:5173`）をブラウザで開きます。

### プロダクションビルド

```bash
npm run build
```
ビルド成果物のローカルプレビュー:
```bash
npm run preview
```

### シミュレーションテストの実行

```bash
npx tsx tests/simulation_test.ts
```

## 🔒 プライバシー

- 名前やメールアドレスなどの個人情報は入力しません。アカウント登録もありません。
- 発見した化合物やクエストの達成状況、設定は、使っている端末のブラウザ (localStorage) にだけ保存され、サーバーには送信されません。
- 公開サイトでは、利用状況を把握するために Google アナリティクス (Google タグマネージャー経由) を使う場合があります。これは `GTM_ID` を設定してデプロイしたときだけ読み込まれ、ページの閲覧数などを個人を特定しない形で集計します。
