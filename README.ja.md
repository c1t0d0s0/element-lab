## 🌟 概要

**元素ラボ (Element Lab)** は、TypeScript と HTML5 Canvas で構築されたインタラクティブな化学学習シミュレーションです。
画面上に元素（原子）や化合物を配置し、バーナーで加熱したり冷却スプレーで冷やしたり、点火スパークを散らしたりしながら、リアルな化学反応（水の合成、鉄のサビ、燃焼、酸化還元、中和など）や物理現象（浮力、状態変化、熱伝導）を体験できます。

文部科学省の学習指導要領（中学校理科第2分野・高等学校化学基礎/化学）の学習内容に準拠しており、遊びながら確かな化学の基礎知識を身につけることができます。

## ✨ 主な特徴

- **⚛️ 全118元素完全収録の周期表**
  - 水素（H：原子番号1）からオガネソン（Og：原子番号118）まで全元素データを網羅。
  - 各元素の原子番号・族・周期・分類・原子半径・融点/沸点・原子量・モル質量・文科省学習ポイントを収録。
  - **原子半径の視覚的スケーリング**: 周期表の傾向に合わせて、ヘリウム（He）は小さく、フランシウム（Fr）は大きく直感的に描画。

- **💨 リアルな物理演算・熱力学シミュレーション**
  - **浮力と空気抵抗**: 空気の平均分子量（約 $28.8\text{ g/mol}$）との比較により、軽い気体（$\text{He}$ や $\text{H}_2$）は上空へとふわふわ浮かび、重い気体（$\text{CO}_2$ など）は下方へ沈降。
  - **温度と相変化（状態変化）**: 粒子の温度と融点・沸点に応じて、リアルタイムに「固体 🧊」「液体 💧」「気体 ♨」へと変化。
  - **熱伝導と対流**: 粒子同士の衝突による熱の移動、加熱された気体の上昇気流（熱気球効果）やブラウン運動をシミュレート。
  - **高温発光・危険性表示**: 鉄（$\text{Fe}$）は500℃以上で赤熱（オレンジ・白熱発光）。有毒気体（$\text{CO}$ や $\text{HCl}$）には警告オーラを表示。

- **🔥 充実した化学反応エンジン**
  - **水の合成**: $2\text{H} + \text{O} \to \text{H}_2\text{O}$、または水素ガスと酸素ガスの燃焼爆発 $2\text{H}_2 + \text{O}_2 \to 2\text{H}_2\text{O}$。
  - **鉄のサビ（常温 vs 高温）**:
    - *赤サビ（酸化鉄(III)）*: 常温で水と酸素の両方に触れることで徐々に赤サビ（$\text{Fe}_2\text{O}_3\cdot n\text{H}_2\text{O}$）が進行。
    - *黒サビ（四酸化三鉄）*: 赤熱した鉄（>500℃）に高温の水蒸気（>100℃）を通すと、良質な保護被膜である黒サビ（$\text{Fe}_3\text{O}_4$）と水素ガス（$\text{H}_2$）が発生。
  - **燃焼と有毒気体**:
    - マグネシウムの燃焼: $2\text{Mg} + \text{O}_2 \to 2\text{MgO}$（まばゆい白色の閃光と発熱を伴い、白色粉末の酸化マグネシウムを生成する中学2年最重要実験）。
    - 二酸化炭素中でのマグネシウム燃焼: $2\text{Mg} + \text{CO}_2 \to 2\text{MgO} + \text{C}$（CO₂中でも燃焼が持続し、黒い炭素が析出）。
    - 完全燃焼: $\text{C} + \text{O}_2 \to \text{CO}_2$（二酸化炭素）。
    - 不完全燃焼: $2\text{C} + \text{O}_2 \to 2\text{CO}$（無色・無臭で人体に猛毒な一酸化炭素）。
    - メタン燃焼: $\text{CH}_4 + 2\text{O}_2 \to \text{CO}_2 + 2\text{H}_2\text{O}$。
  - **酸化還元実験**:
    - 酸化銅の炭素還元: $2\text{CuO} + \text{C} \to 2\text{Cu} + \text{CO}_2$（中学理科の最重要実験）。
  - **酸・アルカリ・中和**:
    - 中和反応: $\text{HCl} + \text{NaOH} \to \text{NaCl} + \text{H}_2\text{O}$（食塩水と中和熱の生成）。
    - 気体の中和（白煙反応）: $\text{NH}_3 + \text{HCl} \to \text{NH}_4\text{Cl}$（塩化アンモニウム白煙）。
    - 金属と酸の反応: $\text{Zn} + 2\text{HCl} \to \text{ZnCl}_2 + \text{H}_2$（亜鉛が溶けて水素が発生）。
  - **🧪 自由実験（サンドボックス） & 工業的製法**:
    - **過酸化水素水（$\text{H}_2\text{O}_2$）の合成と触媒分解**:
      - 合成: $\text{H}_2\text{O} + \text{O} \to \text{H}_2\text{O}_2$
      - $\text{MnO}_2$ 触媒分解: $2\text{H}_2\text{O}_2 + \text{MnO}_2 \to 2\text{H}_2\text{O} + \text{O}_2 + \text{MnO}_2$（激しい酸素ガス発生・触媒は不変）
    - **硫酸（$\text{H}_2\text{SO}_4$）の接触法プロセス**:
      - $\text{S} + \text{O}_2 \to \text{SO}_2 \to 2\text{SO}_3 \to \text{H}_2\text{SO}_4$（硫黄の燃焼・酸化・水和による強酸生成）
    - **鉄と硫黄の化合（中学2年最重要）**:
      - $\text{Fe} + \text{S} \to \text{FeS}$（硫化鉄の生成・赤熱反応） & $\text{FeS} + 2\text{HCl} \to \text{H}_2\text{S} + \dots$（腐卵臭気体発生）
    - **ハーバー・ボッシュ法（アンモニア合成）**:
      - $\text{N}_2 + 3\text{H}_2 \to 2\text{NH}_3$
    - **石灰石・石灰水サイクル**:
      - 熱分解: $\text{CaCO}_3 \to \text{CaO} + \text{CO}_2$（生石灰の生成）
      - 水和発熱: $\text{CaO} + \text{H}_2\text{O} \to \text{Ca(OH)}_2$（激しい発熱湯）
      - 二酸化炭素検出: $\text{Ca(OH)}_2 + \text{CO}_2 \to \text{CaCO}_3 + \text{H}_2\text{O}$（石灰水の白濁）
      - 気体発生: $\text{CaCO}_3 + 2\text{HCl} \to \text{CaCl}_2 + \text{H}_2\text{O} + \text{CO}_2$（激しい発泡）

- **🎯 学習クエスト & 化合物図鑑**
  - 「水を作ろう」「軽い気体を浮かべよう」「赤サビと黒サビを作ろう」など、理科の単元に沿ったミッション形式で学べるクエスト機能。
  - 新たに合成した化合物を記録し、日常生活での用途や文科省の重要知識を学べる化学図鑑。
  - 粒子にカーソルを合わせるかタップするだけで温度・状態・分子量・解説が確認できるインスペクター。

- **🔊 Web Audio API による効果音**
  - 外部音声ファイル不要のプロシージャル（動的合成）サウンドエンジン（火花音、水滴音、爆発音、サビ進行音、クエスト達成ファンファーレなど）。

- **📱 PC・スマホ両対応（マルチプラットフォーム）**
  - マウス操作はもちろん、スマートフォンのタッチ操作にも最適化。

## 🎮 操作方法・ツール一覧

| ツール | アイコン | 説明 |
| :--- | :---: | :--- |
| **配置 (Spawn)** | 🧪 | 下部パレットまたは周期表から選択した元素・化合物をキャンバスに配置します。 |
| **加熱 (Heat)** | 🔥 | バーナーで周囲を加熱（最高1800℃）。状態変化や熱化学反応を起こします。 |
| **冷却 (Cool)** | ❄️ | 冷却スプレーで周囲を急速冷却（氷点下へ）。気体を凝縮・液体を凍結させます。 |
| **点火 (Spark)** | ⚡ | 電気火花を散らし、水素爆発などの可燃性混合気に引火させます。 |
| **耐熱壁 (Wall)** | 🧱 | 粒子や熱を遮断する固定壁を配置し、実験室内に密閉容器を作れます。 |
| **消去 (Erase)** | 🧹 | ブラシが触れた粒子を個別に消去します。 |
| **観察 (Inspect)** | 🔍 | 粒子を選択し、現在の温度・状態・質量・文科省学習ポイントを確認します。 |

## 🚀 セットアップと実行方法

### 必要要件

- Node.js（v18.0.0 以上を推奨）
- npm（v9.0.0 以上）

### インストール

1. リポジトリをクローンまたはディレクトリに移動します:
   ```bash
   cd element-lab
   ```

2. 依存パッケージをインストールします:
   ```bash
   npm install
   ```

### 開発サーバーの起動

```bash
npm run dev
```
ターミナルに表示されたURL（通常は `http://localhost:5173`）をブラウザで開きます。

### プロダクションビルド

```bash
npm run build
```
ビルド成果物のローカルプレビュー:
```bash
npm run preview
```

### シミュレーションテストの実行

```bash
npx tsx tests/simulation_test.ts
```
